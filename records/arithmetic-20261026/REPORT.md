## 结论

显式算术证据提供了小幅增益：完整 validation 从735/798提高至738/798；困难子集从292/355提高至295/355。纠正5题、退步2题，净增3题。五个纠正案例的原选择都含真实的数字等式错误。两个退步案例暴露了题意理解和解析覆盖的问题。这是补充信息的正面信号，不是完整数学推理验证，也不是大幅突破；反复开发使用过的validation上仅三题差距，还不能当作稳定泛化收益或排行榜成绩。

## 先做训练集诊断，再允许一次拟合

只重算明确数字等式：用有界语法树和精确分数计算，支持基本运算、简单幂、嵌套分数及有限LaTeX包装。小数结果按显示精度允许半个末位单位的舍入；变量、百分数歧义、带余数/近似表述和无法完整解析的表达式留为未知。未发现矛盾不等于推理正确；从不硬淘汰发现矛盾的候选。

在19,020条训练候选上，14,602条至少含一个可检查等式（76.77%）；共检查35,314个等式，367个不等，涉及331条候选。最终答案正确候选中的标记率为47/14,353=0.3275%；最终答案错误且能解析的候选中为264/3,796=6.9547%。有标记且最终答案可解析的候选中84.89%答错。

现有排序器训练错误中，21题选中了含矛盾候选、且存在无标记正确候选；另有8道当前答对题包含相反风险。前者是参考答案揭示的可纠错空间，不是实际达到的提升。1,909道困难训练题的四个候选有算术特征差异。

预设的覆盖、区分度与纠错空间门槛通过。由Codex按seed17分层抽查20个标记案例（正确最终答案/错误最终答案各10）：19个明确数字不等，1个存在隐式舍入歧义。该抽查不是独立人工标注，不用于估计全体误报率。训练诊断发现并修复了金额符号跨行、删除片段后拼接表达式、百分数惯用写法、带余数除法的误报；共三次训练诊断、零次诊断阶段拟合。细节见`DEVELOPMENT.md`、`manual-audit.json`，早期输出保留在`development/`。规则在读取本轮validation前冻结。

## 一个配置，其他保持不变

原1028维特征后加入四项：检查等式数的log1p、矛盾等式数的log1p、矛盾比例、无可检查等式指示。标准化只拟合train，原1028维的均值和尺度与原最佳完全一致。

同题正确/错误候选形成6,516对、2,114个有效训练题；每题总权重1，沿用成对逻辑损失。C=0.01，lbfgs，max_iter=2000，tol=1e-6，seed17，无截距。只拟合一次，43次迭代收敛，未追加系数、规则或网格。新增维度也改变了联合优化后的原特征权重，因此收益属于整套新增特征配方；没有声称每个改判都完全由单个矛盾惩罚造成。

四项标准化系数依次为0.07637、-0.14678、-0.07532、-0.01753。模型整体降低有矛盾候选的分数，也略偏好可检查内容更多的候选。后者有可能奖励格式，而不是真正的逻辑质量。

```sh
.venv/bin/python -B -m unittest -v test_arithmetic_evidence test_contract

.venv/bin/python -B upstream/code/predict.py --method submission_arithmetic.py --checkpoint artifacts/arithmetic-C001-20261026.npz --split validation --output results/predictions/arithmetic-reproduction.json
.venv/bin/python -B upstream/code/score_predictions.py --split validation --predictions results/predictions/arithmetic-reproduction.json
```
